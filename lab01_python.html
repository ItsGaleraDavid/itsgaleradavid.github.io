Building a lightweight system telemetry monitor

September 15, 2026

I wanted a straightforward way to inspect raw OS metrics without deploying heavy monitoring frameworks. The solution was simple: write a backend loop in Python using asyncio and psutil to capture hardware stats, serializing the data packets into JSON streams.

Since GitHub Pages serves static files and doesn't run background processes on the cloud, this is built as a local diagnostic tool. The frontend client establishes a WebSocket connection directly to the local host machine, keeping dependencies to an absolute minimum.

Telemetry client capturing live metrics locally. (Hover to zoom)

The implementation strips away unnecessary abstractions, focusing purely on clean event loops and readable socket handling. No frameworks, zero bloat.
