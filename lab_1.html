Setting up a local OpenSimulator sandbox

September 13, 2026

Got tired of cloud-hosted virtual worlds and overly polished corporate spaces, so I set up a local OpenSimulator instance running on port 9000. It's a completely self-hosted sandbox backed by a local SQLite database—just a standalone process running in a terminal window.

Getting a modern viewer like Firestorm to talk to a local loopback address takes a bit of friction-fighting. The client is heavily geared toward public online grids, meaning you have to bypass its web directory, type the URI manually, and provision accounts directly through the server console.

First boot on the local loopback interface.

There's something satisfying about a virtual world that vanishes the second you close a terminal window. No cloud infrastructure, no external telemetry—just local state and physics.

Next up is messing around with physics overrides and testing custom scripts. Just a private lab to see how things break and rebuild them from scratch.
