My personal space.
2026-08

Starting this with plain HTML. No frameworks, no heavy themes, no WordPress dashboard asking for updates every two days, and no annoying cookie banners tracking things nobody cares about.

It's funny how people complicate something so simple. They want a massive CMS just to write four thoughts or save a script. But if you want a real space (a site that actually feels like yours and not some rented template) you have to build the walls yourself.

A personal website should be like an old notebook. Timeless. HTML from the nineties still opens in any browser today. Try opening some modern web app full of dependencies twenty years from now; it’ll probably collapse into a hell of broken libraries. Not this. This stays.

It's expandable. If tomorrow I want to add a page about a script that just crashed in my face, a dumb 3D model, or a 3 AM thought, I just make a file and that's it. No intermediate plugins.

Total control. That's what this is about.
